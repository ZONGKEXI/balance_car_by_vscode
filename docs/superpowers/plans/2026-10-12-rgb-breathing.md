# RGB 呼吸灯实施计划

> 用户已要求直接修改源码，并明确允许修改电池采样与 TIM2。本计划在当前共享工程执行；无 Git 仓库，不创建提交或 worktree。

**Goal:** 行驶时五颗 RGB 灯持续同步呼吸，避免软件发送阻塞控制或屏蔽编码器中断。

**Architecture:** HAL_GetTick 主循环调度亮度和电池采样；TIM2_CH1 PWM 配合 DMA1_Channel5 异步传送彩灯；数据缓冲在传输期间保持不变。

**Tech Stack:** STM32F103、CubeMX HAL、C11、CMake。
